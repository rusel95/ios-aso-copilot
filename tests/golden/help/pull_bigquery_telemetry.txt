usage: pull_bigquery_telemetry.py [-h] [--store STORE] [--days DAYS] [--export-md] [--export-json]
                                  [--weekly]

Pull BigQuery in-app telemetry.

options:
  -h, --help     show this help message and exit
  --store STORE  Path to marketing store folder
  --days DAYS    Days to look back (0 for all-time)
  --export-md    Save markdown report to metrics/telemetry_latest.md
  --export-json  Save raw JSON to metrics/telemetry_latest.json
  --weekly       Store every closed week the event tables hold whole and metrics/telemetry.csv
                 does not, then stop
